# Stage 1: 첫 바람의 골짜기 (The Valley of the First Wind)

어미 민들레에서 떨어진 홀씨 하나가 바람을 타고 **약 5분(300초), 2.1 km**를 날아갑니다.
새벽 언덕에서 출발해 초원, 안개 호수, 고대 협곡, 빛의 폭포를 지나 고원의 **성소의 숲**에
내려앉아 씨를 내립니다. 분위기의 기준은 *Flower*(thatgamecompany)처럼 조작보다 흐름을
즐기는 평온한 비행입니다.

- 시간대: 해 뜰 무렵의 황금빛(태양 고도 9°). 태양은 항상 진행 방향 앞쪽에 있어서,
  플레이어는 늘 빛을 향해 날아갑니다. 역광 덕분에 풀, 꽃잎, 솜털이 빛나 보입니다.
- 이야기 흐름: 물을 거슬러 올라가는 여정입니다. 호수에서 강을 따라 협곡을 지나고, 폭포를
  올라 강의 근원인 샘 옆 비옥한 땅에 도착합니다.

## 구역별 타임라인

| 시간 | 구역 | 길이/속도 | 경험 | 주요 요소 |
|---|---|---|---|---|
| 0:00–0:40 | **새벽 언덕** | 느림 (≈5 m/s) | 이륙과 조작 익히기. 거대한 풀잎 사이에서 떠올라 골짜기를 처음 내려다봄 | 어미 민들레, 형제 민들레 수천 송이 |
| 0:40–1:40 | **속삭이는 초원** | 빠름 (≈8 m/s) | 꽃밭 위를 스치며 활공하는 해방감 | 5색 꽃 군락, 참나무 숲, **선돌 고리(바람 관문 1)**: 경로가 고리 안으로 내려감 |
| 1:40–2:50 | **안개 호수** | 중간 (≈7 m/s) | 수면 위 낮은 비행, 고요함, 반영 | 물안개, 수련과 연꽃, 자작나무 섬 3곳 |
| 2:50–3:40 | **고대 숲 협곡** | 중간 | 신비로움, 좁은 공간감 | 높은 암벽, 거대 참나무, 반딧불이, 강, **고대 아치(바람 관문 2)** |
| 3:40–4:15 | **빛의 폭포** | 상승 | 클라이맥스. 상승 기류를 타고 약 80 m 절벽을 솟구쳐 오름 | 계단식 폭포, 물보라 안개 |
| 4:15–5:00 | **성소의 숲** | 느림 (≈5 m/s) | 여정의 끝, 천천히 내려가 착지 | 분홍빛 성스러운 나무, 샘, 고대 기둥 고리, 빛나는 정령 입자 |

정확한 구간 시각과 속도는 `stage1_layout.json`의 `zones`에 있고, 스크립트가 경로 길이와
고도 변화를 반영해 합계가 정확히 300초가 되도록 속도를 자동으로 맞춥니다.

## 바람 (`wind`)

| 종류 | 위치 | 효과 |
|---|---|---|
| breeze_ribbon | 초원, 호수 | 약한 가속 (×1.3–1.4) |
| gate | 선돌 고리, 고대 아치 | 통과하면 강한 가속 (×1.8)과 연출 |
| updraft | 폭포 | 수직 상승 (+6 m/s) |
| calm | 착지 직전 140 m | 감속 (×0.6), 부드러운 착지 |

## 파일

| 파일 | 내용 |
|---|---|
| `build_stage1.py` | 전체를 생성하는 Blender(bpy) 스크립트. 시드가 고정돼 있어 결과가 매번 같음 |
| `stage1_terrain.glb` | 지형(8 m 격자, 정점 색) + 호수, 강, 개울, 샘, 폭포 메시 |
| `stage1_props.glb` | 소품 라이브러리: 나무 9종, 성스러운 나무, 바위 4종, 선돌, 아치, 기둥, 꽃 5색, 풀, 민들레, 수련, 연꽃, 발광체 |
| `stage1_layout.json` | 시간이 매겨진 비행 경로(2 m 간격), 구역, 바람, 랜드마크, 소품 배치 |
| `make_map.py` | 레벨 지도 생성 → `renders/stage1_map.png` |
| `renders/*.png` | Cycles 미리보기 렌더 |

좌표계는 JSON과 glb 모두 glTF 규약(Y-up, 미터)입니다.

### 게임 엔진에서 쓸 때
- **풀**은 개수가 너무 많아 목록에 넣지 않았습니다. 경로에서 120 m 이내, 경사가 완만하고
  (normal.y > 0.8) 물이 아닌 곳에 셰이더나 GPU 인스턴싱으로 뿌립니다.
- **꽃과 민들레**는 타입당 최대 12,000개만 JSON에 넣었습니다. `density_multiplier`만큼
  각 지점 주변에 더 뿌리면 렌더와 같은 밀도가 됩니다.
- 소품은 `InstancedMesh` 같은 GPU 인스턴싱으로 그리세요. 소나무만 2만 그루가 넘습니다.
- 안개(`lighting.fog_density`), 물안개, 빛줄기, 물보라는 엔진 쪽에서 볼류메트릭 효과나
  파티클로 다시 만들어야 합니다. glb에는 들어 있지 않습니다.

## 다시 만들기

```bash
pip install bpy numpy matplotlib   # bpy = Blender 5.x 파이썬 모듈
python3 build_stage1.py --fast     # 저해상도 확인 (약 3분)
python3 build_stage1.py            # 최종 렌더 포함 (4코어 CPU에서 약 30–40분)
python3 build_stage1.py --no-render
python3 make_map.py
```
